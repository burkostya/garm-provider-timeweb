# Initial experimental release

`garm-provider-timeweb` is an external provider for GARM that manages ephemeral GitHub Actions runner VMs on Timeweb Cloud.

This is a **prerelease**. Automated checks use a local HTTP test server and exercise provider behavior without creating cloud resources. A real Timeweb create → bootstrap → job → delete smoke test has not yet been performed. Follow `docs/smoke-test.md` before using the provider for production workloads.

## Included

- GARM external provider protocol `v0.1.0`, targeting GARM `v0.2.1`.
- VM lifecycle integration with the Timeweb Cloud API.
- Linux `amd64` runner support and GARM bootstrap generation.
- TOML configuration with inline token or token file authentication.
- Installation, on-demand scaling, networking, and smoke-test documentation.
- Static provider executables for Linux `amd64` and `arm64` controller hosts.
- SHA-256 checksums and version, commit, and date metadata.

## Before first use

Prepare a Timeweb API token that permits unattended server deletion, select an existing network with working runner egress, and choose catalog image and preset IDs for the same availability zone. Shared networking is managed separately from runner VMs. The initial configuration and network prerequisites are documented in the README and setup guide.

The `arm64` release asset runs the provider on an `arm64` controller. It does not enable `arm64` Timeweb guests. NixOS guests and private cloud connectivity require an appropriate image and bootstrap configuration and have not been validated against Timeweb.
